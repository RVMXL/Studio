# RVMXL // СТАНЦИЯ ВАЙБОВ

Студия вайбкодинга: приёмник сигналов из пурпурного вакуума. Не страница, а радиостанция — настраивайтесь на частоты проектов RVMXL.

**Сайт:** https://rvmxl.github.io/Studio/

## Сигналы в эфире

| Частота | Канал | Что это |
|---------|-------|---------|
| 87.9 | СТАНЦИЯ | Манифест студии и карта сигналов |
| 92.1 | HumNote | Ментальный диктофон мелодий: напой — получи MIDI/WAV (YIN, offline) |
| 96.4 | OTGLens | Офтальмологический тренажёр-сканер зрения |
| 100.7 | DocGen | Генератор документов без сети |
| 104.8 | AutoAlarm | Умный будильник для студентов |
| 108.0 | FridgeChef | Рецепты из того, что есть в холодильнике |
| 111.9 | WarpScout | GUI-скаут для навигации по данным |

## Философия

- **0 серверов** — вся логика на устройстве
- **0 аналитики** — никто не следит за вами
- **100% офлайн** — работает в самолёте, в подвале и на Марсе

## Технологии

Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · three.js (пульсар) · Zustand · Web Audio API

## Управление станцией

- `←` `→` `↑` `↓` — настройка частоты
- `0—6` — прямой выбор канала
- кнопка «ЗВУРК» — включить аудиосопровождение

## Деплой

Сайт собирается GitHub Actions в статический экспорт и публикуется на GitHub Pages автоматически при пуше в `main`.

```bash
bun install
bun run build:export   # статическая сборка в .next-export/
bun run dev            # локальная разработка на :3000
```
